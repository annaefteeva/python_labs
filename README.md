# Лабораторная работа №1

**Тема:** Окружение, Git и синтаксис Python. Задача «Миллиард строк»

## Цель работы

Освоить настройку окружения Python, работу с Git и GitHub, а также реализовать программу для обработки большого объёма данных.

## Структура проекта

- `.gitignore` — список файлов и папок, исключённых из Git.
- `.python-version` — используемая версия Python.
- `pyproject.toml` — конфигурация проекта.
- `uv.lock` — файл фиксации зависимостей.
- `data/` — папка с исходными данными и вспомогательными скриптами:
  - `generate_measurements.py` — генерация тестовых измерений.
  - `weather_stations.csv` — данные о метеостанциях.
  - `check.py` — проверка результатов программы.
- `README.md` — описание проекта.
- `main.py` — основной файл программы.
